# Generic CiA 402 CST 兼容画像 — 事实来源与边界

本插件是 **"通用 CiA 402 CST（转矩模式）伺服的 SIMULATED 画像"**，用于验证 5 字节
PDO + 转矩模式 Tier0 行为。**不冒充任何厂商设备**，设备身份用我方自有 VID/PID（R2）。

## 采用/引用的公开来源（R5）

| 来源 | 用途 | 链接 |
| --- | --- | --- |
| CiA — CiA 402 伺服驱动 profile（公开摘要） | 控制字/状态字/模式（CST=10）/对象 `0x6071`/`0x6077` 语义 | https://www.can-cia.org/cia-402 |
| ETG — EtherCAT 规范与设备 profile（ETG.1000/ETG.6010 公开入口） | PDO 由 SM2/SM3 承载、CoE 邮箱 | https://www.ethercat.org/ |

> **R1**：没有把任何厂商 ESI/PDF/固件复制进仓库；以上只作为公开规范入口。
> **R2**：Vendor ID `0x00000EC5` / Product Code `0x0000E5E2` 为我方自有（SIMULATED）。
> **R3**：不声称隶属/背书/认证。

## 本画像声明的事实（通用 CiA 402 结构，非厂商确认）

- 5 字节 RxPDO `0x1600`：`0x6040` 控制字（16）+ `0x6060` 模式（8）+ `0x6071` 目标转矩（16）。
- 5 字节 TxPDO `0x1A00`：`0x6041` 状态字（16）+ `0x6061` 模式显示（8）+ `0x6077` 实际转矩（16）。
- `0x6502 = 0x3AD`（pp/pv/tq/hm/csp/csv/cst）。

## ⚠️ Tier0 简化（不是真实伺服行为）

1. **转矩不模拟运动/负载**：Operation enabled 时 `0x6077` 仅镜像 `0x6071`，禁用后归零；
   不做转矩环、限幅、摩擦或电流模型。
2. 状态机时序（Ti=0/1 边界）、`0x6071` 单位/缩放、故障码表均未实现。
3. 本画像只用于协议/框架预回归，**不构成**对真实伺服的性能或一致性声明。
