SDO 浏览（只读 API）

经 GET /sdo?index&sub&slave 从运行时对象字典读取（不经过 mailbox/CoE 往返）。 需先在上方填写 API 地址（--serve 的地址）并载入；请求会带当前站号（B55 起后端校验 0-based）。

写操作默认关闭：仅当服务端以 --serve-write 启动、且对象在 manifest 中声明 writable 时才会成功；身份/配置类对象（0x1000/0x1008/0x1009/0x1010/0x1011/0x1018/ 0x1C12/0x1C13）与长度不匹配会被服务端拒绝。本页无法探测写开关，最终以服务端响应为准。 确认框会显示对象名/位长/旧值/新值/站号；STALE/暂停状态下会额外提示数据可能过期；STOPPED 状态下写入按钮禁用。

⚠️ token 模式：若服务端以 --serve-token-env 开启鉴权，浏览器 fetch 无法自动携带 Authorization 头，请经反向代理注入请求头，或改用 curl -H "Authorization: Bearer <token>"；本页不保存 token。
