EC-Sim 状态视图

数据源：ec-sim-esc --dump-state 生成的 JSON（M2 WebUI 起点；状态/PDO/拓扑/指标只读， SDO 面板只读浏览，写入需显式开启且二次确认）。 可直接把 JSON 文件拖入下方，或先执行 ec-sim-esc --dump-state --manifest plugins/… > web/state.json 或 ec-sim-esc --dump-dict --json --manifest plugins/… > web/dict.json 后 python3 -m http.server 8080 --directory web，页面会自动读取同目录 state.json。

载入状态

或从只读 API 载入： （ec-sim-esc --serve 127.0.0.1:8090 --manifest plugins/…）

SDO 浏览（只读 API）

经 GET /sdo?index&sub 从运行时对象字典读取（不经过 mailbox/CoE 往返）。 需先在上方填写 API 地址（--serve 的地址）并载入。

写操作默认关闭：仅当服务端以 --serve-write 启动、且对象在 manifest 中声明 writable 时才会成功；身份/配置类对象（0x1000/0x1008/0x1009/0x1010/0x1011/0x1018/ 0x1C12/0x1C13）与长度不匹配会被服务端拒绝。本页无法探测写开关，最终以服务端响应为准。

⚠️ token 模式：若服务端以 --serve-token-env 开启鉴权，浏览器 fetch 无法自动携带 Authorization 头，请经反向代理注入请求头，或改用 curl -H "Authorization: Bearer <token>"；本页不保存 token。
